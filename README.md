# 🌐 ICT5101 - Internet of Things Project

This repository contains the coursework developed as part of the **ICT5101 - Internet of Things** study unit at the University of Malta.

The project is divided into two main components:

- **PartA/**  
  Focuses on the design and implementation of an IoT plant monitoring system. This includes Arduino-based sensor readings, circuit documentation, data logging and a Python dashboard for visualising soil moisture readings over time.

- **PartB/**  
  Focuses on predictive maintenance within an Industrial IoT context. This part uses a synthetic smart factory sensor dataset to apply machine learning techniques for predicting machine maintenance needs based on usage and sensor readings.

Each component is organised independently and includes its own files, documentation, and implementation details.

**This repository contains the complete project work developed in fulfilment of the ICT5101 Internet of Things study unit.**
